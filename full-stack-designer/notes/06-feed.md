# 6장. 피드 화면

**화면 변화**: 와이어프레임이 썸네일·노란 핀·단계 배지가 있는 카드 3장짜리 완성 피드가 된다.

## 만든 파일 (새로 8개, 바꾼 것 2개)

작은 컴포넌트를 먼저 만들고 → 조합해 큰 컴포넌트를 만들고 → 프레임에 배치.

| 구분 | 파일 | Figma로 치면 |
|---|---|---|
| 부품 | `stage-badge` | 단계 배지 (variant 3개) |
| 부품 | `user-avatar` | 프로필 동그라미. 사진 없으면 첫 글자 |
| 부품 | `empty-state` | 빈 화면 안내 |
| 조합 | `project-card` | 작업 카드 |
| 조합 | `project-grid` | 카드를 담는 오토 레이아웃 그리드 (3열 → 2열 → 1열) |
| 조합 | `tag-filter` | 태그 칩 묶음 |
| 조합 | `site-header` | 상단 내비게이션 바 |
| 프레임 | `layout.tsx` | 모든 화면에 깔리는 마스터 프레임 |
| 프레임 | `page.tsx` | 피드 화면 프레임 |
| 프레임 | `not-found.tsx` | 404 화면 프레임 |

## 작업 카드의 레이어 구조

```
📦 작업 카드 (전체가 클릭 영역)
 ├─ ▢ 썸네일 (4:3 고정)
 │    ├─ 🖼 이미지 (꽉 채우고 넘치면 자름)
 │    └─ 📍 노란 핀 (오른쪽 위 absolute, 피드백 수)
 ├─ ▢ 본문: 제목 / 요약 2줄 말줄임 / 태그 칩
 └─ ▢ 하단 줄: 프로필 · 이름 · "3시간 전" · 단계 배지(오른쪽 끝)
```

- 색은 전부 디자인 토큰에서 온다. 색상값을 직접 적은 곳이 없다.
- 썸네일이 없을 때의 empty variant가 있다.
- hover하면 그림자가 진해진다 (While hovering 인터랙션).

## 태그 칩은 왜 주소창을 바꾸나

인터랙티브 컴포넌트(같은 화면 안에서 토글)가 아니라, **칩마다 다른 프레임으로 연결한 프로토타입**이다.

- `#웹` → `/?tag=웹`
- 덕분에 뒤로 가기, 링크 공유, 새로고침 후 유지가 된다.
