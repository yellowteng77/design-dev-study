# 7장. 상세 화면과 피드백 남기기

**화면 변화**: 카드를 누르면 큰 사진, 번호 핀이 붙은 피드백 목록, 피드백 입력 폼이 있는 상세 화면이 열린다.

## 만든 파일 (새로 4개)

| 파일 | Figma로 치면 |
|---|---|
| `feedback-list` | 피드백 목록. 번호 핀·프로필·종류 배지·본문 |
| `kind-picker` | 세그먼트 컨트롤 (좋은 점 / 제안 / 질문) |
| `feedback-section` | 피드백 영역 전체 그룹. 유일하게 사용자 조작에 반응 |
| `projects/[id]/page.tsx` | 상세 화면 **템플릿 프레임**. `[id]`는 "여기에 작업 번호가 들어온다"는 빈칸 |

## 버튼이 스스로 활성화되는 이유 — 컴포넌트에 "변수"가 생겼다

Figma 프로토타입의 변수 + 조건과 같다.

- 변수 `입력한 글`
- 조건: 5자 미만이면 Disabled variant, 5자 이상이면 Default

`feedback-section`이 기억하는 변수 3개:

| 변수 | 언제 바뀌나 | 무엇이 반응하나 |
|---|---|---|
| 입력한 글 | 한 글자 칠 때마다 | 버튼 활성/비활성 |
| 고른 종류 | 세그먼트 누를 때 | 선택된 탭 |
| 피드백 목록 | 제출할 때 | 새 항목 추가, 개수 변경 |

변수를 가진 부품에는 파일 맨 위에 `"use client"`(사용자 화면에서 반응한다는 표시)를 붙인다.

## 새로고침하면 사라지는 이유

변수는 지금 보는 브라우저 화면 안에만 있다. 프로토타입을 처음부터 재생하면 변수가 초깃값으로 돌아가는 것과 같다. 실제 저장은 2부에서.
