# 8장. 작업 올리기 화면

**화면 변화**: 상단 바의 "작업 올리기"를 누르면 왼쪽 입력 폼, 오른쪽 카드 미리보기 화면이 열린다.

## 만든 파일 (새로 2개)

| 파일 | Figma로 치면 |
|---|---|
| `project-form` | 입력 폼 + 미리보기 카드를 묶은 컴포넌트. 미리보기는 6장 작업 카드의 인스턴스 |
| `projects/new/page.tsx` | 작업 올리기 화면 프레임 |

## 폼과 미리보기는 같은 변수를 본다

```
        ┌──── 변수: 제목 ────┐
  [입력칸] 변수를 바꿈     [카드 인스턴스] 변수를 읽어 보여 줌
```

카드 인스턴스의 컴포넌트 속성(제목 텍스트, 썸네일, 단계 variant)을 변수에 바인딩한 것과 같다. 입력칸과 카드가 서로 직접 대화하지 않고, 가운데 변수 하나를 함께 본다.

## 미리보기 카드 = 피드 카드 + `Preview = true`

불리언 속성을 켠 인스턴스다.

- 눌러도 이동하지 않는다 (아직 갈 상세 화면이 없음)
- hover 그림자가 없다
- 빈 칸은 placeholder 문구로 채운다

피드 카드 디자인을 고치면 미리보기도 함께 바뀐다.
