# 10장. 자연어로만 만들기

**방식 변화**: 코드를 받아 적지 않고, 빈 폴더에서 Claude에게 "이런 화면 만들어 줘"라고 말로 시킨다. 결과는 매번 조금씩 다르다.

## 핵심: 브랜드 가이드(`CLAUDE.md`)를 먼저 건넨다

외주 디자이너에게 일을 맡기는 상황과 같다.

- 가이드 없이 부탁하면 → 그럴듯하지만 그 사람의 오래된 템플릿과 기본 색으로 만들어 온다.
- 브랜드 가이드를 건네고 부탁하면 → 우리 컬러, 우리 컴포넌트 규칙, 우리 정리 방식대로 만들어 온다.

| | 가이드 없이 | 가이드 넣고 |
|---|---|---|
| 겉모습 | 요청대로 | 요청대로 |
| 색 | 기본 파랑 | 우리 코발트, 노란 핀 |
| 정리 | 파일 하나에 몰아넣음 | 컴포넌트별로 나눔 |
| 도구 버전 | 구버전 | 우리와 같은 최신 |

겉으로는 둘 다 잘 만든 것 같지만, 속을 열면 가이드 없는 쪽은 우리 프로젝트가 아니다. 1~9장을 받아 적은 이유가 이 차이를 알아보는 눈을 기르기 위해서다.

## 역할 구분

| 무엇을 맞추나 | 무엇이 맞추나 |
|---|---|
| 만드는 방식 (도구, 정리 규칙, 토큰 사용) | `CLAUDE.md` |
| 디자인 (레이아웃, 색, 간격) | Figma 연결 또는 자세한 부탁 |

순서: 규칙 → (있으면) Figma → 자연어 부탁.

## 실습 메모

- 터미널에서 `claude`를 실행하면 그 폴더 기준으로 Claude가 뜬다.
- `CLAUDE.md`는 Claude를 **띄우기 전에** 폴더에 넣어야 읽힌다.
- 한글 입력 상태에서는 `` ` `` 키가 `₩`가 되어 `` Ctrl+` `` 단축키가 안 먹는다.
