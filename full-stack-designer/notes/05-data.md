# 5장. 데이터 모양과 가짜 데이터

**화면 변화**: 버튼·배지 견본 화면이 사라지고, 가짜 작업 3개가 글자만 있는 목록(와이어프레임)으로 보인다.

## 만든 파일 (새로 3개, 바꾼 것 1개)

| 파일 | Figma로 치면 |
|---|---|
| `lib/types.ts` | **컴포넌트 속성 정의**. 작업 카드에는 제목·설명·썸네일·단계가 있고, 단계는 작업 중/리뷰 요청/최종안 중 하나만 고를 수 있다 |
| `lib/mock-data.ts` | **더미 텍스트를 채운 시안**. 정해 둔 칸에 가짜 내용을 넣음 |
| `lib/data.ts` | **라이브러리 연결 통로**. 화면은 콘텐츠를 항상 여기서만 받는다 |
| `app/page.tsx` (바꿈) | **점검용 임시 프레임**. 6장에서 교체 |

흐름: 칸을 정하고(속성) → 더미로 채우고(시안) → 통로로 잇고(연결) → 프레임에 배치.

## 왜 연결 통로(`data.ts`)를 따로 두나

Figma 라이브러리 연결과 같다.

- 시안 10장이 라이브러리 컴포넌트를 쓰면, 라이브러리만 교체해도 10장이 한꺼번에 바뀐다.
- 컴포넌트를 detach해서 붙여 두면 10장을 일일이 고쳐야 한다.

```
지금 (1부)   화면들 ──→ data.ts ──→ 더미 시안
나중 (2부)   화면들 ──→ data.ts ──→ 실제 데이터 저장소
                        ↑ 여기 연결만 바꿈
```

2부에서 실제 저장소로 바꿀 때 화면은 하나도 고치지 않는다.
