# Full Stack Designer

Figma로 디자인한 디자인 크리틱 서비스 **Crit Board**를 실제로 돌아가는 웹 서비스로 만드는 수업입니다.

- 1부(1~9장): 교재 코드를 따라 만들며 "이 줄은 무엇을 하는가"를 익힘
- 1부 보충(10~14장): 코드를 쓰지 않고 Claude에게 말로 시켜 같은 화면 만들기
- 2부: 가짜 데이터를 실제 저장소(Supabase)로 바꾸고 로그인·저장 붙이기

## 노트

| 장 | 노트 | 한 줄 요약 |

| 5장 | [데이터 모양과 가짜 데이터](notes/05-data.md) | 칸을 정하고, 더미로 채우고, 통로로 잇는다 |
| 6장 | [피드 화면](notes/06-feed.md) | 작은 컴포넌트 → 큰 컴포넌트 → 프레임 |
| 7장 | [상세 화면과 피드백](notes/07-detail.md) | 컴포넌트에 처음으로 "변수"가 생긴다 |
| 8장 | [작업 올리기](notes/08-new-project.md) | 입력칸과 미리보기가 같은 변수를 본다 |
| 9장 | [디자인 시스템 페이지](notes/09-design-system.md) | 라이브러리 원본을 그대로 늘어놓은 스타일 가이드 |
| 10장 | [자연어로만 만들기](notes/10-vibe.md) | 브랜드 가이드(CLAUDE.md)를 먼저 건넨다 |

## 기본 용어 사전

| 개발 용어 | 디자이너 언어로 |
|---|---|
| `.ts` 파일 | 보이지 않는 설정. 변수 패널, 컴포넌트 속성 정의 |
| `.tsx` 파일 | 캔버스 위의 프레임. 눈에 보이는 화면을 그리는 파일 (x = 화면이 있다) |
| 타입(type) | 컴포넌트 속성 정의. 어떤 칸이 있고 무엇을 고를 수 있는지 |
| 상태(state) | 프로토타입 변수. 사용자가 조작하면 바뀌고 화면이 따라 반응 |
| props | 인스턴스에 넘기는 컴포넌트 속성 값 |
| 커밋(commit) | 버전 히스토리에 이름 붙여 저장하기 |
