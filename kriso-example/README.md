# K3I 디자인 시스템 실습

Figma 디자인 시스템을 **Lit 웹 컴포넌트로 한 번만 구현**해서 React·Vue·순수 HTML 어디서나 똑같이 쓰는 방법을 배우는 3강짜리 수업. 실습 주제는 자율운항선박 대시보드.

## Figma로 비유하면

지금까지 만든 컴포넌트는 그 프로젝트 안에서만 쓰는 **로컬 컴포넌트**였다. 이 수업은 컴포넌트를 **팀 라이브러리로 퍼블리시**해서, 개발팀마다 도구가 달라도 같은 버튼을 쓰게 만드는 일이다. Lit은 "어느 개발 환경에도 꽂히는 범용 컴포넌트"를 만드는 도구.

## 내가 만들 것

### 1강 — Figma와 코드가 쌍둥이인 라이브러리
- Figma Variables: 코드의 토큰으로 자동 생성 (라이트/다크)
- Foundations 페이지
- Component Set 3종(버튼·입력칸·카드), variant 이름을 코드와 글자까지 일치
- 역방향 동기화: Figma에서 바꾼 값을 코드로
- Code Connect: Dev Mode에서 실제 코드 보이기
- 응용: 회원가입 카드 화면을 Figma ↔ 코드 양방향으로

### 2강 — 컴포넌트에 상태 입히기
- 스위치의 상태(켜짐/꺼짐, 누르는 중, 비활성)를 Figma variant로
- 조건에 따라 거부되는 스위치("원격 잠금")
- React 화면에서 쓰기

### 3강 — 선박 대시보드를 말로 고치기
- OpenBridge(선박 UI 표준 디자인 시스템) 기반, 밝기 모드 4가지 × 선박 상태 6가지
- 색·상태 문구·우선순위·레이아웃을 자연어로 변경
- 종합 미션: 충돌 위험 판단 화면을 말 한 번으로 코드·Figma까지 반영
